## 2. 值得吸收的点

### 2.1 教师版/学生版双视图 ★立刻采纳（低成本高价值）

智卷工坊同一份试卷数据出两个视图。我们的练习卷导出补齐：

| 版本 | 内容 | 用途 |
| --- | --- | --- |
| 学生版 | 题目 + 作答留白，无答案无评分点 | 发放 |
| **教师批改版** | 题目 + 参考答案 + 评分点（Rubric）+ 每题预期薄弱生提示 | 随卷发给教师，批改时逐题给分有依据 |

这把"评分点/Rubric"从系统内的暗知识变成纸面可见——**批改时按得分点给分，回流的数据才能支撑 Error Pattern 维度（08 模块 P2 激活条件）**。是打印卷反哺数据质量的关键一招。

### 2.2 考点细目表 × 难度阶梯 —— 班级统一题的生成范式 ★采纳

MathBank 的 AI 组卷用「双向细目表」（考点 × 难度矩阵选题）。这是**教师教研最熟悉的范式**。我们的 Planner 生成班级统一题（common 60%）时对齐这个心智：

```
统一题生成 = 教学范围内选考点 × 覆盖难度阶梯（易/中/难比例可调）
展示给教师的计划预览就是一张细目表（行=知识点，列=难度，格=题数）
```

个性化题保持我们的画像桶方案不变（这是差异化所在），但**统一题用细目表**——教师看得懂、改得动，符合"教师策略优先于算法"。

### 2.3 排版参数体系（智卷工坊的配置面清单）★采纳为导出模板规格

把它验证过的排版配置面直接抄进 13-file 的练习卷模板规格：

```
纸张 A4（默认）/A3；页边距（Word 风格预设）；中文字号（正文小四，题干五号可选）；
行距（1.5 默认）；页眉（班级/考试名，左中右）；页脚页码（"第 X 页/共 N 页"）；
题目间留白按题型（填空线 / 解答题区高度 = 难度×行数）
```

MathBank 的中国考试版式细节（密封线、答题卡预设）P1 不做（我们是日常练习卷不是统考卷），**A3 答题卡预设列入 P2**（配合答题卡采集，见 06）。

### 2.4 拖拽排序 + 留白高度调整（MathBank）★P2 参考

练习卷预览的逐题微调（拖拽换序、调整某题作答区高度）是教师真实高频需求。P1 先做按钮式换题（原型已有「换一题」），P2 加拖拽。

### 2.5 分页保真预览 ★采纳

「预览分页 = 打印分页」必须成立，否则教师对打印结果的信任崩塌。实现走 13-file 的同一渲染管线（预览用屏幕版 CSS，导出用打印版，共享分页计算）。

## 3. 明确不吸收的点

| 项 | 理由 |
| --- | --- |
| AI 自由生成整卷（智卷工坊主路线） | 与需求 4.3 相悖：我们题库优先保证可控，AI 变式 P3 且必须过校验器 |
| 本地 XeLaTeX 排版引擎 | 桌面单机约束下的选择；WeasyPrint 的日常练习卷质量足够。若 P3 后有"统考级"导出需求再评估 LaTeX 后端（保持模板双后端抽象即可） |
| 高考 19 题预设 | 场景不匹配（K12 日常教学，不是高考模拟） |
