# 试卷编辑器（手动组卷 · 排版 · 打印预览）实施方案

> 参考来源：智卷工坊编辑器体验（[DreZeo/examcraft-ai](https://github.com/DreZeo/examcraft-ai)，MIT）
> 范围决策：**先做编辑器本体，右侧 AI 对话通道暂不实现**（AI 方案见 [AI对话组卷实施方案](./AI对话组卷实施方案.md)，其后插回）
> 可交互原型：[paper-editor.html](../../../design/prototype/paper-editor.html)（排版工具栏 / 题库选题 / 新建题目 / 三视图 / 真实分页 / 可打印）
> 归属：09-practice（产物与下游闭环）+ 13-file（导出渲染）
> 日期：2026-09-30

## 一、功能范围

| 能力 | 内容 | 原型对应 |
| --- | --- | --- |
| 出题 | ① **题库选题**：按知识点/题型/难度/关键词过滤，逐题加入；② **手动新建**：题型（单选/填空/解答）+ 题干（填空用 `____` 占位）+ 选项 + 答案 + 知识点 + 难度 + 分值 | 右栏两个 Tab |
| 编辑 | 题干行内直接编辑（contenteditable）；上移/下移/复制/删除；逐题改分值（总分实时联动）；试卷标题编辑 | 悬停题块出现工具条 |
| 排版 | 字号（小四/五号/小五）、行距（1.25/1.5/2.0）、纸张（A4/A3）、边距（标准/窄）、页眉开关 | 工具栏，改动即重排 |
| 预览 | **三视图**：编辑视图（带编辑痕迹）/ 教师预览（答案+评分点红色标注）/ 学生预览（作答留白无答案） | 顶部分段切换 |
| 打印 | 真实分页（A4/A3 尺寸），页眉试卷名+班级姓名日期，页脚"第 X 页/共 N 页"；浏览器打印直接可用，导出 PDF/Word 走 13-file | 🖨 打印按钮 |

**明确不做（本期）**：AI 对话生成（后插）、答题卡版式、拖拽排序（先按钮，拖拽 P2）、选项单独编辑器（改题走新建/重新加）、多人协同。

## 二、与现有设计的关系（不新造闭环）

```
试卷编辑器 ──保存──▶ practice_plan（origin='manual_editor'，strategy 记录排版参数）
                      ↓ 完全复用 09 现有下游
                 预览 → 导出（13-file：学生版 + 教师批改版）→ assign → 批改 → 成绩回流 → mastery 画像
手动新建的题 ──▶ question（source='manual'，status='active'，标注 kp 后进本班题库）
```

| 模块 | 增量 |
| --- | --- |
| 09-practice | `practice_plan.origin` 增加 `manual_editor`；`strategy` JSONB 记录排版 settings；编辑器保存 API |
| 04-question | `source` 枚举增加 `manual`（教师手写题免校验器，但**必须选知识点**才能保存——保住画像可归因） |
| 13-file | WeasyPrint 导出复用编辑器同一 settings（字号/行距/边距/纸张）——**屏幕预览与打印导出共用分页参数**，保证所见即所得 |
| 前端 | 新页面 `paper-editor`（三栏：题目索引 / 纸张分页区 / 题库+新建） |

## 三、前端架构

### 3.1 组件拆分

```
PaperEditor
├─ TypographyToolbar     排版参数 → CSS 变量 → 触发重分页
├─ ViewSegment           三视图切换（body class 切换渲染模式）
├─ QuestionIndex         左栏结构索引（点击滚动定位）
├─ PagedSheet            ★ 分页引擎（见 3.2）
│   ├─ PageHeader        标题 + 班级姓名日期（首页）/ 续页简头
│   └─ PageFooter        页码
├─ QuestionBlock         按 type 渲染模板：choice（选项两列）/ fill（____）/ solve（作答留白 em）
├─ BankPanel             题库过滤与加入（调 04 :select 的轻量版）
└─ NewQuestionForm       手动新建（choice 联动选项输入）
```

### 3.2 分页引擎（核心，原型已实现）

问题：题目流要装进固定尺寸页（A4 = 210×297mm），且**预览分页必须等于打印分页**。

```
算法（块测量装箱，O(n)）：
1. 按 [章节头, 题1, 题2, …] 生成块序列（块 = DOM 元素）
2. 顺序 append 到当前页 .pg-content（overflow:hidden，高度由纸张 flex 撑出）
3. 若 scrollHeight > clientHeight 且页内已有内容 → 开新页，把该块挪过去
4. 全部装完后统一编号页脚

参数变化（字号/行距/边距/纸张）→ 改 CSS 变量 → 重跑装箱
边界：单块超过一页（超长解答题）→ 允许溢出并提示拆题
正式版换 CSS Paged Media / Paged.js 亦可，装箱算法作为兜底与屏幕预览共用
```

### 3.3 题型渲染模板

| 题型 | 渲染 | 教师预览附加 | 学生预览附加 |
| --- | --- | --- | --- |
| 单选 | 题干 + 选项两列（A. B. C. D.） | 【答案】C | — |
| 填空 | 题干内 `____` 原样 | 【答案】值 | — |
| 解答 | 题干 + 作答留白（难度×行数，em 单位随字号缩放） | 【答案】+【评分点】 | 留白区 |

编辑视图额外：悬停工具条（分值/上移/下移/复制/删除）+ 知识点标签 + 留白区横纹底提示。

## 四、数据与 API 增量

```
POST /api/practice-plans:save-draft     {plan_id?, title, questions[], settings{}}  自动保存（防抖 2s）
GET  /api/practice-plans/{id}/editor    编辑器载入（含题块渲染所需全部字段）
POST /api/questions:manual              手动建题（source='manual'，kp 必填）
GET  /api/questions:select-lite         题库面板（kp/type/难度/关键词过滤，不分页预览用）
```

`questions[]` 项：`{question_id | manual_draft, seq, score}`——编辑器内新建未保存的题先持前端草稿，保存时一并落库。

## 五、实施切分

| 里程碑 | 内容 | 工作量 | 交付 |
| --- | --- | --- | --- |
| M0 编辑器 | 三栏布局 + 分页引擎 + 三视图 + 编辑操作 + 题库面板/新建表单 + 浏览器打印 | 前端 6-8 天 | 原型已验证，可直接进开发 |
| M1 保存与闭环 | save-draft API + question:manual + 接通导出（13-file，学生版+教师批改版）+ assign | 后端 3-4 天 + 前端 2 天 | 编辑器产出的卷走通回流 |
| M2 体验增强 | 拖拽排序、逐题难度/留白微调、A3 答题卡版式、最近使用记录 | 3-4 天 | — |
| M3 AI 通道 | 即 [AI对话组卷实施方案](./AI对话组卷实施方案.md) 的 Phase B/C：聊天面板作为右栏第三个 Tab 插入，编辑器成为 AI 产物的落地载体 | — | 交互壳已就绪 |

> 关键点：**编辑器是壳，AI 是输入通道之一**。先有壳，AI 后插——这正是"先不用右边 AI 部分"的架构含义。

## 六、验收标准（DoD）

- [ ] 分页保真：屏幕预览页数 = 打印页数（A4/A3 × 字号×行距×边距组合抽测）
- [ ] 三视图：同一数据源，学生预览无答案痕迹（DOM 级检查），教师预览含答案+评分点
- [ ] 编辑：行内改题、增删移复制、改分值 → 结构索引与总分实时正确
- [ ] 手动新建的题落库带 kp（无 kp 不允许保存）且出现在题库面板
- [ ] M1：编辑器保存 → 导出两版 → assign → 成绩回流，全链路跑通
- [ ] 排版 settings 随 plan 持久化，重新打开还原

## 七、风险与边界

| 风险 | 对策 |
| --- | --- |
| 分页测量与浏览器打印细微不一致 | 打印走同一 settings + 打印 CSS 固定页参数；导出 PDF 由 WeasyPrint 生成并回归抽测 |
| 教师手写题质量无校验 | 免校验器（教师自己的题），但 kp 必填 + 该题仅本班可见（school_id 隔离） |
| contenteditable 富文本粘贴污染 | 输入约束为纯文本（paste 拦截）；富格式 P2 再议（先对齐 04 的 Markdown+KaTeX 决策） |
| 超长题溢出单页 | 提示拆题，不静默截断 |
