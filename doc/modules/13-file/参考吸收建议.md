# 参考吸收建议 · 文件与导出（file）

> 分析对象：[JudgePeach/math-question-bank](https://github.com/JudgePeach/math-question-bank)（MathBank）· [DreZeo/examcraft-ai](https://github.com/DreZeo/examcraft-ai)（智卷工坊）
> 关联度：MathBank ★★☆（备份/发布工程化）· 智卷工坊 ★★☆（数据目录安全迁移、密钥管理）
> 日期：2026-09-30 · 基于两仓库 README 与目录结构分析

## 1. 项目速览（与本模块相关的部分）

**MathBank 工程化实践**：

```
- 数据迁移：db_migrations.py 版本化迁移，升级前自动备份（备份优先）
- 备份恢复：scripts/backup 完整备份（含逐文件 SHA-256 清单）；restore 校验清单 + 服务停机锁
- 发布工程：build_release 校验固定 SHA-256 的官方运行时、白名单、RELEASE-MANIFEST.json、
           包外 .zip.sha256
- 渲染缓存：paper_helper.py 的 LaTeX/PDF 编译 LRU 缓存（重复编译去重）
```

**智卷工坊工程化实践**：

```
- 数据目录迁移：先完整复制到新目录 → 成功后切换指针 → 旧目录保留为备份（可选删除）
- 密钥管理：API Key 存系统钥匙串，不落配置文件明文
```

## 2. 值得吸收的点

### 2.1 备份包带 SHA-256 清单 + 恢复前校验 ★立刻采纳

我们已定「事件表是不可再生资产，异地备份最高优先级」，但没定**备份包的形态**。采纳 MathBank 规格：

```
备份包 = {db_dump.sql.gzip, objects/ 目录, manifest.json}
manifest.json = 逐文件 SHA-256 + 版本号 + 时间 + 租户数
恢复流程 = 校验清单 → 停机锁（拒绝写入）→ apply → 抽查事件数
```

把"恢复演练"做成一条 `ops/` 脚本命令（月度演练进运维日历）——**没演练过的备份等于没有备份**。

### 2.2 存储位置变更的时序纪律 ★采纳（写进模块原则）

智卷工坊的目录迁移时序（复制 → 切换 → 保留旧目录）适用于我们一切涉及对象存储/卷变更的操作（MinIO 扩容、私有化数据搬迁）：

```
1. 完整复制到新位置（校验哈希）
2. 切换配置指针（一次性，可回滚）
3. 旧位置保留 N 天后清理
禁止：边迁移边写、先删后拷
```

### 2.3 私有化离线安装包的发布规格 ★采纳（P2 私有化部署前置）

学校内网部署需要离线安装包，MathBank 的 Release 工程直接可抄思路：

```
离线包 = docker-compose + 镜像 tar + 初始化脚本 + INSTALL-MANIFEST.json（逐文件 SHA-256）
包外附 .sha256 供校验；安装脚本先验签再执行
```

### 2.4 导出渲染缓存 ★采纳

MathBank 对 LaTeX 编译做 LRU 去重缓存。我们的 WeasyPrint 练习卷导出同理：同一 `practice_plan + 模板版本` 的渲染结果缓存（file_id 复用），教师反复点导出/预览不重复渲染。缓存键含模板版本号——**模板改版后旧缓存自动失效**。

### 2.5 密钥不落明文 ★采纳

智卷工坊把 API Key 放钥匙串。服务端对应做法：LLM 密钥走环境变量/secret 管理，配置文件与健康检查接口中脱敏；私有化部署的安装向导引导管理员录入而非写死。

## 3. 明确不吸收的点

| 项 | 理由 |
| --- | --- |
| 便携包内置 Python/VC++ 运行时（MathBank 桌面分发） | 我们是服务端 docker-compose 形态，不需要桌面运行时打包 |
| 单机 SQLite 的快照式备份 | 我们 PG 用 pg_dump + WAL 归档，对象存储单独走 2.1 的清单方案 |
