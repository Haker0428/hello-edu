## 1. 模块定位与边界

**职责**：所有 LLM 调用的唯一入口——Provider 抽象（云/私有化切换）、结构化输出约束、变式题校验器、评测集与质量回归。

**铁律（架构不变量 4）**：LLM **永远不直接写状态**，只产生待确认草稿。本模块不持有业务表。

## 2. 对外接口（模块内部 Service，不暴露 HTTP）

## 3. Provider 抽象（ADR-6）

```python
class LLMProvider(ABC):
    name: str
    @abstractmethod
    def complete(self, messages: list[dict], schema: dict,
                 temperature: float = 0.1, max_tokens: int = 4096) -> dict: ...
    # 要求：JSON Schema 约束输出（response_format / guided decoding）

# 实现：
#   OpenAICompatibleProvider  → 云端 API（默认）
#   vLLMProvider              → 私有化部署（"数据不出校"形态）
# 部署配置（.env）：AI_PROVIDER / AI_MODEL / AI_BASE_URL / AI_API_KEY
# 运行时不可混用（整个部署指向一个 Provider），切换 = 迁移 + 评测回归
```

## 4. 三个能力的 Prompt 规格

### 4.1 拆题（split_paper）

```
system: 你是试卷结构化助手。从试卷文本中提取每道题，严格输出 JSON，不要输出任何其他内容。
schema:
{ "questions": [ { "seq": int, "type": "choice|fill|judge|solve",
                   "stem": str, "options": [str]?, "answer": str?, "score": float } ],
  "total_score": float }
参数：temperature 0.05（结构任务求稳）
重试：结构校验失败 → 错误信息回喂重试 ≤ 2 次（见 05 §4.3 校验规则）
输入预处理：页眉页脚过滤、按块拼接、页码标记注入（帮助 LLM 定位跨页题）
```

### 4.2 标注（annotate_question）

```
user 消息结构（关键：候选约束注入）：
  【知识点候选】（只能从下列编号中选择，禁止编造）
  1201 有理数运算 — 有理数四则与乘方 …（每项：编号/名称/一句话描述/层级）
  【题目】{stem}
schema:
{ "mappings": [ { "kp_id": int, "weight": float, "confidence": float, "reason": str } ] }
后校验（服务端）：kp_id ∈ 候选集，否则丢弃该条并把题级置信度降 0.2
weight 服务端归一化；confidence ∈ [0,1]
```

### 4.3 图谱冷启动草稿（build_graph_draft，离线）

```
输入：教材目录（章节结构）
输出 schema：{ nodes: [{layer, name, semantic_hint, objectives[], common_errors[]}],
              edges: [{from, to}] }
人工审核 checklist 见 03 §4.4 —— LLM 只出草稿，运营审定后发布
```

### 4.4 变式生成（generate_variant，P3）

```
约束：变式与母题的知识点映射必须一致（结构不变，数字/语境变换）
schema：{ stem, answer, variant_note }  # variant_note 说明变换点
必须过校验器（§5）才可入库，verify_status 流转：pending → passed/failed
```

## 5. 变式校验器（P3，两道防线之二）

```
verify(mother, variant):
  1. 方程/计算类：sympy 符号求解 —— 母题答案与变式答案各自可解且自洽
  2. 应用题：数值代入一致性（题设数字与答案联合校验，如行程问题距离=速度×时间）
  3. 映射一致性：kp 映射集合与母题完全相同（强约束）
  任一失败 → 丢弃（verify_status=failed，进评测集供 prompt 改进）
```

## 6. 评测集与质量回归

```
数据来源：paper_question.llm_raw / ann_raw 与教师修正结果的差异（teacher_fixed 标记）

指标：
  拆题：题号/分值准确率、题干编辑距离、结构校验通过率
  标注：kp 集合 Jaccard、weight MAE、自动通过率（0.9 阈值下的）
回归流程：换模型 / 改 prompt → 必须跑评测集 → 指标不回退才可上线
```

## 7. 边界情况与错误处理

| 场景 | 处理 |
| --- | --- |
| LLM 超时/限流 | 指数退避重试 ×3 → 步骤 failed（05 状态机可手动 retry） |
| 输出不在 schema 内 | 重试（错误回喂）≤ 2 次 → failed |
| 幻觉 kp_id | 服务端候选校验兜底（§4.2），丢弃 + 降置信 |
| 内容安全（题目文本异常） | Provider 侧内容过滤 + 结果标记人工审查 |
| 成本控制 | 同 paper 结果缓存（不重复调用）；月度 token 预算告警 |

## 8. 验收标准（DoD）

- [ ] Provider 切换：同一测试集在云/私有化两 Provider 下评测集指标达标注档
- [ ] 拆题：10 份真实试卷准确率 ≥ 90%（05 联调口径一致）
- [ ] 标注：候选外 ID 100% 被服务端拦截
- [ ] 评测集回归流水线可一键执行并出报告
- [ ] （P3）变式校验器：构造错误答案的变式 100% 被拒
