# 原型走查与改进清单（全页面串联评审）

> 走查范围：design/prototype/ 全部 8 个业务页 + 登录页
> 走查路径：登录 → 试卷接入 → 成绩导入 → 教学首页 → 热力图（证据抽屉）→ 学生画像 → 练习生成 → 试卷编辑器 → 题库管理 → 回到首页
> 日期：2026-09-30 · 结论：核心闭环已可演示，**串联断点 7 处已当场修复**；其余改进空间按 P1/P2 分级列出，含 2 项需要产品决策

## 一、已当场修复（P0 · 串联断点）

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | 学生画像页只能看李想，热力图抽屉/首页点「画像」跳过去永远是默认学生 | student.html 支持 `?student=` 直达，下拉同步选中 |

## 二、改进空间清单

### A · 流程串联（P1 优先）

| # | 问题 | 建议 |
| --- | --- | --- |
| A1 | 练习生成导出后没有"下一步"引导，闭环在教师视角断在打印 | 导出成功态给三步提示：打印发放 → 批改 → 成绩导入回流（文案即可） |
| A2 | 试卷接入向导只有 step3 有界面：上传页、拆题校验报告页缺失 | 补两屏：① 上传拖拽页；② 拆题校验报告（题号连续性/分值总和校验、逐题可改）——这是建立教师信任的第一屏 |
| A3 | 成绩导入独立进入时，step1「选择考试」无界面（只有从 paper 跳来才顺） | 补考试选择列表（历史考试 + 状态 + 「新建导入」） |
| A4 | 编辑器右栏题库面板与题库管理页是两套独立 mock：编辑器新建的题说"进本班题库"但在 bank.html 看不到 | 共享一份题库数据文件（prototype 层面）；正式实现天然无此问题（同一 question 表） |

## 三、建议处理顺序

1. **先做决策**：B1（出卷入口是否合并）——影响后续导航与页面归属
2. **P1 批次**（半天工作量）：C1 配比联动预览、A1 闭环终点提示、A5 抽屉跳转、E1 细目表模式
3. **P2 批次**（按需）：A2/A3 补向导前两屏、C2-C6、B2-B5、D1/D2、E2-E4、F1-F3
4. D3 不处理（正式实现由单测保障）

## 四、走查中确认无需改动的点（健康项）

- 六档掌握度配色、风险三档、低置信角标在全部页面口径一致
- "数据截至 10-28" 时间戳全站统一
- 核心叙事人设（李想前置断点/张浩遗忘/刘婷应用弱/去分母班级性薄弱）在首页、热力图、画像三页数据互相印证
- 每页均贯彻"异常才处理 + 动作带上下文"的产品原则（本次修复后链路真正闭合）
